# Go-Cycle 🌱🚴‍♂️

Go-Cycle is a sustainable, green initiative-driven startup idea focused on revolutionizing short-distance commuting while promoting environmental responsibility. Our mission is to reduce carbon emissions and promote a healthier, eco-conscious lifestyle by encouraging the use of cycles for daily travel.

## 🌍 Project Overview

Go-Cycle aims to create a platform that enables users to:

- Rent or share eco-friendly cycles through a digital platform
- Track carbon savings and promote environmental awareness
- Build a cycling community with rewards for consistent usage
- Educate people on sustainable transportation options

Our platform brings together innovation, technology, and sustainability in a seamless web experience that showcases the core values of Go-Cycle.

## 🚀 Getting Started

### Clone the Repository
```bash
git clone https://github.com/Vejandlachakrish/Go-Cycle.git
cd Go-Cycle
```
Open the Webpage Locally
Simply open the index.html file in your browser:

```bash
start index.html   # For Windows
open index.html    # For macOS
```
